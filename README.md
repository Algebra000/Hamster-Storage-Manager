# 仓鼠存储管理器（ROLAND 版本）

仓鼠存储管理器是自写自用的一款面向仓鼠党的存储分类管理器，该软件以轻量、快速、定制化且易于拓展为原则，采用前后端html/python3分离架构。ROLAND版本是其中前端后端必须在同台设备上运行的版本(本地版)。

本项目仍在持续开发中。首次公开发布前，建议先在不包含旧 Git 历史的全新仓库中检查待提交文件。


## 开始使用

仓鼠存储管理器的所有功能都来自于其上的各种模块，自身仅提供运行这些模块的平台，甚至具体界面都由模块决定(布局模块)。本项目目前已包含treemap、classify_shower这两个默认功能模块以及一个简易的布局模块（位于 `frontend\frame.js`）。关于管理器与功能模块和布局模块的协作模式以及怎么编写这两种模块，详见[模块设计](./docs/总设计文档/模块化设计思路.txt)。

## 目录概览

- `frontend/`：各种模块的前端部分。
- `backend/`：仓鼠存储管理器的主后端及各种功能模块的后端部分、配置文件。
- `工具链/`：与模块配套的工具；
- `关联项目/`：一些功能的实验代码。
- `docs/`：设计文档与功能添加记录文档；
- `build/`：发布文件清单与构建脚本。
